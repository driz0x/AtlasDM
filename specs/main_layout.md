# Main Layout Specification

## Background

Main Layout defines the primary structure of the AtlasDM user interface. It serves as the foundation for all visual components introduced in later milestones.

---

## Goals

- Create the main application layout.
- Reserve space for the Toolbar.
- Reserve space for the Sidebar.
- Reserve space for the Main Content area.
- Reserve space for the Status Bar.

---

## Non Goals

- Download list
- Queue management
- Buttons
- Icons
- Functional widgets

---

## Functional Requirements

FR-1

Application shall display a Main Window.

FR-2

Application shall include a Toolbar placeholder.

FR-3

Application shall include a Sidebar placeholder.

FR-4

Application shall include a Main Content placeholder.

FR-5

Application shall include a Status Bar placeholder.

---

## Acceptance Criteria

- Main Window is displayed.
- Layout is visible.
- Placeholder widgets are positioned correctly.
- Theme is applied to the entire layout.
