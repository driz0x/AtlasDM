# Sidebar Specification

## Background

The Sidebar provides primary navigation within AtlasDM. It allows users to switch between major sections of the application.

---

## Goals

- Create a reusable Sidebar widget.
- Display navigation items.
- Integrate the Sidebar into MainWindow.
- Apply the active theme.

---

## Non Goals

- Navigation logic
- Page switching
- Download management
- Settings functionality

---

## Functional Requirements

FR-1

Application shall display a Sidebar.

FR-2

Sidebar shall contain the following items:

- Downloads
- Queue
- History
- Settings

FR-3

Sidebar shall be displayed on the left side.

FR-4

Sidebar shall have a fixed width.

---

## Acceptance Criteria

- Sidebar is visible.
- Navigation items are visible.
- Theme is applied.
- Main Layout remains unchanged.
